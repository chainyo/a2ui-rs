# Writing guide

Use ASD-STE100 Issue 9 for new documentation, Rustdoc, comments, and agent instructions.
Use the [official standard](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf) for the rules and dictionary.
A summary or automated check does not establish full conformity.

- Write short sentences in the active voice.
- Give one instruction or fact in each sentence.
- Use a consistent name for each concept.
- Use technical names when an approved word cannot preserve the meaning.
- Preserve protocol identifiers, commands, links, and exact quotations.
- Do not use semicolons or double hyphens as prose punctuation.
- State implemented behavior separately from planned behavior.
- Do not change upstream submodule files to apply this guide.
