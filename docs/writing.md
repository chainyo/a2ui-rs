# Documentation standard

Use ASD-STE100 Issue 9 for project documentation, Rustdoc, comments, and agent instructions.
Use the [official standard and dictionary](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf) during writing and review.

1. Use approved words with their approved meanings and parts of speech.
2. Use technical nouns and verbs as specified in the standard.
3. Use the same term for the same item.
4. Write in the active voice.
5. Use the imperative form for instructions.
6. Give one instruction in each procedural sentence. Use a maximum of 20 words.
7. Give one topic in each descriptive sentence. Use a maximum of 25 words.
8. Use a maximum of six sentences in each descriptive paragraph.
9. Use lists for procedures and for sets of related items.
10. Preserve protocol identifiers, commands, links, and exact quotations.

Describe API contracts, procedures, and design rules.
Use test reports for coverage counts. Use release records for publication details.
Keep progress reports out of the documentation.
Do not use semicolons or double hyphens as punctuation in prose.
Keep the upstream submodule files in their original form.
